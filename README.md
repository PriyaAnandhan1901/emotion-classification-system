# Facial Emotion Classification System

Detects 7 emotions in real-time using deep learning.

## Tech Stack
- Python
- CNN
- TensorFlow
- FER-2013 Dataset

## Results
- 72% Test Accuracy
- 7 Emotion Classes
- Data Augmentation & Dropout used

## How to Run
1. Clone this repo
2. Install requirements: pip install -r requirements.txt
3. Run: python emotion.py
